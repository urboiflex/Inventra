Methodology

Hold-out split: Each product's weekly demand series is split into a training set (all weeks except the last {{ test_weeks }}) and a test set (last {{ test_weeks }} weeks). The model is trained only on the training set.

SES out-of-sample: The optimal multi-step forecast for SES (no trend or seasonality) is the last estimated level repeated for all horizons — a flat-line projection.

MA-4 out-of-sample: The 4-week window rolls forward, substituting previous forecasts for unknown future actuals when the window overlaps the test period.

Promotional weeks: Weeks with abnormally high discounting are replaced by the non-promotional median before training, so promotional spikes do not inflate the baseline.

MAE: Mean Absolute Error — average |actual − forecast| across test weeks. Lower = better.

RMSE: Root Mean Square Error — penalises large errors more than MAE. Lower = better.
